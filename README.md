# Глоссарий: SCRUM в образовании

Веб-презентация-глоссарий, объясняющая ключевые термины гибкой методологии SCRUM в контексте образовательного процесса.

## О проекте

Этот проект представляет собой интерактивную веб-презентацию из 10 слайдов, созданную с использованием HTML, CSS и JavaScript. Каждый слайд содержит определение одного термина, связанного с применением методологии SCRUM в образовании.

## Используемые технологии

- **HTML5** - структура презентации
- **CSS3** - стилизация и анимации
- **JavaScript** - логика переключения слайдов
- **GitHub Pages** - хостинг веб-сайта

## Как использовать

1. Переключайтесь между слайдами с помощью:
   - Кнопок "Влево" и "Вправо" на экране
   - Стрелок на клавиатуре (← →)
   - Свайпов влево/вправо на мобильных устройствах

2. Прямой переход к слайду:
   - Кликните на соответствующий индикатор внизу экрана

## Структура презентации

1. SCRUM в образовании
2. Спринт (Sprint)
3. Учебный бэклог (Educational Backlog)
4. SCRUM-мастер в образовании
5. Учебная команда (Student Team)
6. Ежедневный стендап (Daily Stand-up)
7. Диаграмма сгорания задач (Burndown Chart)
8. Планирование спринта (Sprint Planning)
9. Обзор спринта (Sprint Review)
10. Ретроспектива спринта (Sprint Retrospective)
