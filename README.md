# SCRUM Глоссарий для образовательного процесса

Интерактивный веб-глоссарий с системой тестирования по методологии SCRUM в образовании.

## 🚀 Демо

[Посмотреть на GitHub Pages](https://ваш-логин.github.io/scrum-glossary/)

## 📋 Функциональность

### 📚 Глоссарий
- 10 ключевых терминов SCRUM в образовании
- Поиск по терминам и определениям
- Интерактивная навигация по слайдам
- Категоризация терминов

### 🎯 Тестирование
- 10 вопросов разных типов:
  - Множественный выбор
  - Сопоставление терминов
  - Заполнение пропусков
- Система подсчета баллов
- Сохранение результатов
- Возможность повторного прохождения

### 📊 Отслеживание прогресса
- Статистика изучения терминов
- История тестирования
- Лучшие результаты
- Локальное сохранение данных

## 🛠️ Технологии

- **HTML5** - семантическая разметка
- **CSS3** - адаптивный дизайн, Flexbox, CSS Grid
- **JavaScript (ES6+)** - интерактивность, Local Storage
- **GitHub Pages** - хостинг
- **Git Flow** - стратегия ветвления
